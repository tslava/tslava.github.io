02 · Practice

How I use AI

  1. 01

    Contract first

    Every feature starts as a written contract: interfaces, failure modes, config keys, tests to add. Coding agents implement against it; I review every change.

  2. 02

    A second model as adversary

    Plans and diffs go through an adversarial review by a model from another vendor before merge. It catches what the author model is blind to.

  3. 03

    Measure before shipping

    Prompt and model changes are replayed against real history and compared in numbers, not vibes. Shadow mode first, enforcement second.

  4. 04

    Costs are a feature

    Hard daily budgets, per-feature call caps, a circuit breaker and cheap models in front of expensive ones. The owner hears about failures within minutes.
